## 一、快速入门

### 打开编辑器

在 VS Code 中**单击**工作区中的 CSV、YAML 或 JSON 测试案例文件，即可自动以测试案例编辑器打开。

### 基本操作速查

| 想要做什么 | 操作方式 |
|------------|----------|
| 编辑单元格 | 双击目标单元格 |
| 添加测试案例 | 右键单元格 → 在上方/下方插入行 |
| 修改后推送 | 选中行 → 点击**推送测试案例**按钮 |
| 查找内容 | `Ctrl/Cmd + F` |
| 保存文件 | `Ctrl/Cmd + S`（编辑后自动已保存，无需手动触发） |
| 撤销操作 | `Ctrl/Cmd + Z` |
| 切换到文本编辑 | 工具栏点击 📄 图标 |

## 四、工具栏

### 4.1 搜索与重置

**搜索框**：输入关键词即可实时过滤表格行（150ms 防抖），在所有列中匹配。`Enter` 立即搜索，`Esc` 或点击 `X` 清空。

**重置按钮 ⟳**：一键清空搜索 + 列筛选 + 数据筛选 + 查找面板，并请求从磁盘重新读取最新数据。

### 4.2 数据筛选按钮

五个**互斥**的筛选按钮，同一时间只能激活一个：

| 按钮 | 功能 | 可用条件 |
|------|------|----------|
| ⚠️ 仅看推送失败 | 只显示推送失败的行（红色底色） | 存在推送失败行 |
| ✏️ 仅看已修改 | 只显示本地有修改但未推送的行 | 存在本地修改 |
| 🟢 仅看新增 | 只显示新增但未推送的行（绿色底色） | 存在新增行 |
| 🗑️ 仅看已删除 | 以幽灵行样式展示已删除的行 | 存在删除操作 |
| 🏷️ 仅看已标记 | 只显示被手动标记颜色的行 | 存在标记行 |

> 点击已激活的按钮可取消该筛选。

### 4.3 操作按钮

| 按钮 | 功能 | 说明 |
|------|------|------|
| **推送测试案例**（蓝色） | 将选中行推送到后端系统 | 无选中行时禁用；推送中显示"推送中…"；30秒超时自动解锁 |
| 🔍 查找 | 打开/关闭查找替换面板 | 等同 `Ctrl/Cmd + F` |
| 📄 文本编辑器 | 用 VS Code 默认文本编辑器打开当前文件 | 适合批量编辑 |
| 选区信息（文字） | 实时显示 `已选 N 行，共 M 行` 或 `矩形选区 R×C` | — |

## 五、表格操作

### 5.1 单元格编辑

| 操作 | 方式 | 说明 |
|------|------|------|
| **进入编辑** | 双击单元格 | 变为 textarea 输入框 |
| **提交编辑** | `Enter` | 保存修改，退出编辑模式 |
| **取消编辑** | `Esc` | 放弃修改，退出编辑模式 |

特殊编辑模式：
- **多行编辑**：行高被拉高后，`Enter` 换行，`Ctrl/Cmd + Enter` 提交，`Alt/Option + Enter` 主动插入换行符。多行内容内部使用**真实换行符 `\n`** 存储，CSV 保存时自动以双引号包裹（标准 CSV 格式），不再使用字面量 `\n`
- **浮窗 textarea**：多行编辑模式下输入框以 `position:fixed` 挂在 `body` 上，**不受单元格高度限制**，可完整展示/滚动查看多行内容，表格滚动时同步跟随
- **明细列**：双击打开步骤明细弹窗（不进入 textarea）
- **数组列**：双击打开数组编辑弹窗（不进入 textarea）
- **批量填充**：选区为矩形时，编辑一个格的值会写入整片选区（跳过受保护列）

### 5.2 行操作

| 操作 | 方式 | 说明 |
|------|------|------|
| 在上方/下方插入 N 行 | 右键 → 在上方/下方插入 `[N]` 行 | 菜单项内嵌数字输入框（默认 `1`），改数字后点击行或按回车即批量插入；每行自动生成 `MA`+crypto hex 格式的独立 `testcase_id`，一次操作合并为一步撤销 |
| 在下方复制行 | 右键 → 在下方复制此行 | 深拷贝（`testcase_id` 重新生成，`testCaseNo` 清空） |
| 复制选中多行 | 选中多行 → `Ctrl/Cmd + C` | TSV 格式复制，跨过滤仅复制可见行 |
| 删除行 | 右键 → 删除该行 | 保存 ghost 信息，可在"仅看已删除"中查看 |
| 批量删除 | 选中多行 → 右键 → 删除选中行 (N) | 按降序删除 |

### 5.3 列操作

| 操作 | 方式 | 说明 |
|------|------|------|
| 插入列（左/右） | 右键表头 → 在左/右侧插入列 | 弹出输入框输入列名 |
| 删除列 | 右键表头 → 删除该列 | 受保护列（包括 testcase_id）禁止删除 |
| 重命名列 | 右键表头 → 重命名列 | 受保护列禁止重命名 |
| 清空选中列 | 选中多列 → 右键 → 清空选中列 (N) | 跳过受保护列和隐藏行 |
| 批量填充选中列 | 选中多列 → 右键 → 批量填充选中列 (N)… | 跳过受保护列；数组列以 `; ` 拆分 |

> 受保护列：`testcase_id` 以及后台配置为受保护的业务列（例如某些必填列 / 系统列）。表头可能以中文别名展示，但**不会修改原始文件中的列名字段**。

### 5.4 列宽与行高调整

| 操作 | 方式 |
|------|------|
| **拖动调整列宽** | 拖动列头右侧分割线（最小 40px） |
| **双击自适应列宽** | 双击列头右侧分割线（自动测量内容宽度，上限 600px） |
| **拖动调整行高** | 拖动行号格下方分割线（最小 24px） |
| **双击自适应行高** | 双击行号格下方分割线（自动测量内容高度） |
| **双击恢复默认行高** | 双击行号格 |
| **双击展开/收起多行内容** | 双击行号格在默认高与完整高之间切换 |

> 默认行高下，多行内容以“…”省略号截断。鼠标悬停可查看 Tooltip。拖动行高后表格仅该行采用多行完整展示。

## 六、选区功能（Excel 风格）

### 6.1 行选

| 操作 | 行为 |
|------|------|
| 单击行号格 | 选中该行 |
| `Shift` + 点击行号格 | 区间扩展选行 |
| `Ctrl/Cmd` + 点击行号格 | 离散追加/取消选行 |
| 按住拖动行号格 | 横扫连续选行 |

### 6.2 列选

| 操作 | 行为 |
|------|------|
| 单击表头 | 选中该列 |
| `Shift` + 点击表头 | 区间扩展选列 |
| `Ctrl/Cmd` + 点击表头 | 离散追加/取消选列 |
| 按住拖动表头 | 横扫连续选列 |

### 6.3 单元格矩形选区

| 操作 | 行为 |
|------|------|
| 单击单元格 | 单选该格 |
| `Shift` + 点击单元格 | 以锚点扩展到目标（矩形选区） |
| 按住拖动单元格 | 实时跟随鼠标形成矩形（纵向主导自动锁列） |
| 点击左上角 `#` 角格 | 全选整表 |
| 再次点击 `#` 角格 | 取消全选 |

### 6.4 互斥规则

行选、列选、单元格选区**互相排斥**：激活一种，另外两种自动清除。

### 6.5 过滤模式下的选区

开启任何筛选/过滤时，选区只覆盖可见行，不会误选被隐藏的行。全选（`Ctrl/Cmd + A`）也只全选可见行。

## 八、列筛选功能（漏斗）

每个表头右侧有一个漏斗图标 🔽，点击打开该列的筛选弹窗：

| 元素 | 功能 |
|------|------|
| 搜索框 | 在弹窗内搜索值（自动选中命中项） |
| 清除搜索 | 清空搜索词，恢复全选 |
| 重置 ⟳ | 清空搜索 + 恢复全选 |
| 全选 | 全选/反选当前可见值列表 |
| 清除筛选 | 移除该列的筛选条件 |
| 取消 | 关闭弹窗不应用 |
| 确定 | 应用筛选（至少需选一项） |

**特性**：
- 跨列联动计数：某列弹窗中的计数是"其他列筛选 + 搜索"通过后的行数
- 自动失效保护：编辑后若筛选不再匹配任何行，自动清除并提示
- 空白值显示为 `(空白)`，内部 key 为 `__BLANK__`
- 有筛选条件的列，漏斗图标高亮为蓝色

## 九、查找与替换

通过 🔍 按钮或 `Ctrl/Cmd + F` 打开查找替换面板：

| 元素 | 功能 |
|------|------|
| 查找输入框 | 输入即搜索，自动同步工具栏搜索框 |
| Aa 大小写开关 | 切换区分大小写 |
| 上一个 ↑ / 下一个 ↓ | 导航匹配项 |
| 匹配信息 | 显示 `N / M` 格式 |
| 替换输入框 | 输入替换文本 |
| 替换 | 替换当前匹配项（仅该格第一处） |
| 全部替换 | 替换表格中所有匹配项 |

**限制**：testcase_id 列跳过替换；数组列（string[]/number[]）不支持；过滤模式只搜可见行。

**视觉反馈**：命中格黄色高亮（`highlight`），当前活动格深色（`highlight-active`），匹配文本 `<mark>` 标签。

**展开步骤子表格内的查找高亮**：当"步骤"列处于展开状态时，查找命中**步骤名称 / 数据 / 预期结果**会在对应子单元格内直接高亮匹配文本：
- 步骤名称（`xse-td-desc`）：纯文本，按行 `markText` 高亮
- 数据 / 预期结果（`xse-line` / 分组 chip 结构）：使用结构化高亮（`markTextInStructure`），保留原有 DOM 结构不被破坏

> 详见第二十一章「展开步骤子表格」21.7 节。

## 十、推送功能

### 10.1 推送方式

| 方式 | 操作 |
|------|------|
| 工具栏推送 | 选中目标行 → 点击**推送测试案例**按钮 |
| 右键推送 | 选中目标行 → 右键 → 推送测试案例 (N) |
| 单行快速推送 | 右键某行 → 推送（无选区时自动以右键行作为目标） |

### 10.2 推送流程

1. 选中需要推送的行（可多选）
2. 点击推送按钮
3. 按钮显示"推送中…"并置灰（防重复点击，30 秒超时自动解锁）
4. 弹出推送结果弹窗

### 10.3 推送结果弹窗

| 状态 | 颜色 | 说明 |
|------|------|------|
| 全部成功 | 绿色 | 所有选中行推送成功 |
| 部分成功 | 橙色 | 部分行成功，部分失败（显示失败列表） |
| 全部失败 | 红色 | 所有行失败（显示全部失败列表） |

弹窗功能：失败行明细列表、悬停显示详情、点击行号跳转到主表、一键复制失败明细。

### 10.4 推送后行为

| 行为 | 说明 |
|------|------|
| 回写 testCaseNo | 服务器返回的 testCaseNo 自动回写（绿色高亮） |
| 修改高亮清除 | 推送成功的行，黄色修改高亮消失 |
| 新增高亮清除 | 推送成功的新增行，绿色背景消失 |
| 失败行标记 | 失败行以红色底色高亮，后续可基于"仅看失败"筛选 |
| 累积合并 | 历史失败行保持高亮，本批成功行从失败集合移除 |

### 10.5 推送来源判定

推送时 `sourcePlatform` 字段由以下规则自动判定（优先级从高到低）：

| 优先级 | 条件 | sourcePlatform |
|--------|------|----------------|
| 1 | 文件由插件"新增测试案例"命令创建 | `testAgentMA` |
| 2 | 所选案例中存在以 `TC` 开头的 `testcase_id` | `testAgent` |
| 3 | 其他情况（默认） | `testAgentMA` |

> 判定逻辑为公共方法 `getPushSource(filePath, rows)`，资源管理器右键推送和编辑器内推送共享同一规则。

### 10.6 步骤描述换行格式化

推送时，**步骤描述**和**前置条件**字段中的换行符 `\n` 自动替换为 HTML 换行标签 `<br>`，确保推送到后端后能在 Web 页面中正确展示多行内容。

| 字段 | 转换规则 |
|------|----------|
| 步骤描述（description） | `\n` → `<br>` |
| 前置条件（preCondition） | `\n` → `<br>` |
| 预期结果（expected） | 保持 `\n` 不变 |

> 提供公共方法 `nl2br(v)` 处理转换，统一映射逻辑。 |

## 十一、资源管理器右键推送

除了在编辑器内部推送外，还可以直接从 VS Code **资源管理器**中右键推送，无需打开编辑器。

### 11.1 使用方式

1. 在 VS Code **资源管理器**（左侧文件树）中，找到需要推送的测试案例文件
2. 右键点击文件 → 选择 **推送测试案例**
3. 系统自动打开编辑器（如未打开）并执行推送
4. 推送结果以弹窗形式展示

### 11.2 适用条件

右键菜单中的"推送测试案例"选项仅在文件路径满足以下条件时出现：

```
测试任务/<任意任务名>/测试案例/<任意目录>/xxx.csv
测试任务/<任意任务名>/测试案例/<任意目录>/xxx.yaml
测试任务/<任意任务名>/测试案例/<任意目录>/xxx.yml
测试任务/<任意任务名>/测试案例/<任意目录>/xxx.json
```

即文件必须位于 `测试任务/**/测试案例/` 目录结构下，且是 CSV、YAML、YML 或 JSON 格式。

### 11.3 推送流程

```
资源管理器右键文件
  → 检查文件是否在合规目录下
  → 检查任务是否已绑定（未绑定时弹窗提示）
  → （若编辑器未打开）自动用测试案例编辑器打开文件
  → 等待编辑器前端就绪（最长 8 秒）
  → 解析文件内容为二维数组
  → 调用后端 HTTP 接口推送
  → 推送成功项回写 testCaseNo 到文件
  → 更新快照基线
  → 弹出推送结果弹窗（全部成功/部分成功/全部失败）
```

### 11.4 与编辑器内推送的区别

| 维度 | 资源管理器右键推送 | 编辑器内推送 |
|------|-------------------|-------------|
| 入口 | 文件树右键菜单 | 表格内按钮 / 右键菜单 |
| 编辑器状态 | 自动打开（如未开） | 必须已在编辑器中 |
| 推送范围 | **整个文件**（全部行） | 手动选中的行 |
| 适用场景 | 全新文件首次推送、批量全量同步 | 增量修改、按需推送特定行 |

> ⚠️ **注意**：资源管理器右键推送是**全文件推送**，会将整个文件的所有行都提交到后端。如需按行推送，请在编辑器内选中目标行后推送。

## 十二、本地修改标记与手动标记

### 12.1 自动数据状态标记

| 标记 | 视觉效果 | 含义 | 何时消失 |
|------|----------|------|----------|
| 修改高亮 | 单元格右上角小三角标记 | 该格被编辑但未推送 | 推送成功 |
| 新增高亮 | 整行绿色背景 | 本地新插入的行 | 推送成功 / 删除行 |
| 删除行 | 灰色条纹 ghost 样式 | 已删除但变更未推送 | 推送/撤销变更 |
| 推送失败 | 整行红色背景，时间戳最新时优先在单元格上覆盖 | 上次推送失败（含时间戳） | 重新推送成功 |
| 推送后更新 | 变化单元格黄底、同行其他单元格橙底 | 推送后服务器回写引起的字段变化 | 下次推送/刷新 |

> 推送失败状态 + 失败时间戳会**跨会话保留**（随文件描述一同保存），重新打开仍可看到上次失败行，便于定位修复。

### 12.2 手动颜色标记与筛选

| 操作 | 方式 | 说明 |
|------|------|------|
| 给单元格/行打上标记 | 右键 → 标记颜色 → 选择颜色 | 人工关注某些行/区域，不影响业务数据 |
| 取消标记 | 右键 → 标记颜色 → 清除标记 | 可选区批量清除 |
| 仅看已标记 | 工具栏 🏷️ 按钮 | 与“仅看失败 / 仅看已修改 / 仅看新增 / 仅看已删除”互斥 |

> 标记动作纳入历史栈，支持 `Ctrl/Cmd + Z` 撤销、`Ctrl/Cmd + Y` / `Ctrl/Cmd + Shift + Z` 重做。

## 十四、数据高亮标记说明

### 单元格级标记

| Class / 视觉 | 含义 |
|--------------|------|
| `xs-td-frozen` | 受保护列（`testcase_id` / 后台配置受保护列），不可编辑 |
| `xs-td-ghost` | 已删除行的幽灵单元格 |
| `xs-td-push-updated` | 推送后服务器回写的单元格（黄色） |
| `xs-td-push-updated-row` | 推送后行内发生变化的其他单元格（橙色） |
| `xs-td-push-added` | 推送后新增行的单元格（绿色） |

| `xs-td-overrides-fail` | 失败叠加保护：失败时间早于其他高亮时间时，避免行级红底吞掉黄/橙/绿/手动标记色 |

| `xs-detail-link` | 明细列（蓝色链接样式） |
| `xs-arr-cell` | 数组列单元格 |
| `xs-td-user-marked` + 行内 `background/color` 样式 | 手动颜色标记（右键拉起取色面板选择，本地保存于 `markStore.json`） |

### 行级标记

| Class | 含义 |
|-------|------|
| `xs-tr-push-failed` | 推送失败的行（红色底色；单元格红底实际由 `xs-td-push-failed` 竞争后应用） |
| `xs-ghost-row` | 已删除行的幽灵显示 |
| `xs-tr-resized` | 被手动拖高的行（代码使用，多行编辑模式判定依据） |
| `selected` | 被行选中的行 |

> 说明：失败行内单元格的最终颜色由时间戳竞争决定，失败时间最新时 `xs-td-push-failed` 胜出（全红）；若修改/手动标记/推送后更新等时间晚于失败时间，则叠加 `xs-td-overrides-fail` 保留原色。无独立的 `xs-tr-push-failed-recent` 类。

### 查找高亮

| Class | 含义 |
|-------|------|
| `highlight` | 查找命中的单元格 |
| `highlight-active` | 查找当前活动命中的单元格（更深色调） |

## 二十一、展开步骤子表格

针对结构化文件（YAML / JSON）中包含 `steps` 字段的行，编辑器支持将"步骤"列**原地展开为内联子表格**，无需打开弹窗即可直接查看与编辑每一步的步骤名称、数据、预期结果。

### 21.1 展开 / 收起

| 操作 | 方式 | 说明 |
|------|------|------|
| 展开步骤 | 工具栏点击 **展开步骤** 按钮（仅在含 `steps` 的结构化文件显示） | 所有含步骤的行整表切换为内联子表格 |
| 收起步骤 | 同上按钮变为 **收起步骤** | 恢复为"\[N 项\]"摘要或蓝色明细链接 |
| 表头快捷切换 | 点击 steps 主表头内的 ↡ / ↟ 内联图标 | 与工具栏按钮行为一致，复用同一套逻辑 |
| 持久化 | 切换后即时保存展开态 | 切换 Tab 再切回自动恢复（见第十九章） |

> ⚠️ 展开步骤**仅对 YAML / JSON 生效**：CSV 的步骤列只是合并文本、无嵌套结构，按钮自动隐藏。

### 21.2 子表格结构

展开后，原"步骤"列被替换为 5 个子列（表头底部子表头条）：

```
序号 | 步骤名称 | 预期结果 | 数据 | 操作
```

| 子列 | 内容 | 是否可编辑 | 说明 |
|------|------|-----------|------|
| 序号 | 步骤自然数序号（步骤1 / 步骤2…） | 否 | 圆点样式，只读展示 |
| **步骤名称** | 步骤的 `operation` 字段 | 是 | 即原"步骤描述"列，已更名；为空时显示空白可编辑格 |
| 预期结果 | `ui_expected` / `api_expected` / `db_expected` 三个分组 | 是 | 按【UI检查】/【接口调用】/【数据检查】分组展示 |
| 数据 | `data` 字段 | 是 | 每行一条数据 |
| 操作 | 复制 / 向下插入 / 删除步骤 | 按钮 | 仅样例数据行（frozen）隐藏，保持只读 |

> 注：列名"步骤名称"对应 yaml 中的 `operation` 字段；历史文档/代码中的"步骤描述"即指此列。

### 21.3 内联编辑

- **步骤名称 / 数据 / 预期结果**：直接点击单元格即可编辑（`contenteditable`），失焦自动保存并回写源文件。
- **未修改不保存**：仅点击单元格、未做任何改动就移开焦点，不会触发保存或标黄（方案 A 短路）。
- **预期结果分组**：每个分组有彩色标题 chip（UI=蓝 / 接口=紫 / 数据=绿）；全空分组不渲染空行，仅显示 `+ 分组名` 按钮，点击可补充分组。

### 21.4 步骤级操作（操作列）

| 按钮 | 功能 | 说明 |
|------|------|------|
| 📋 复制 | 复制当前步骤 | 在当前步骤下方插入一份副本（序号从 1 重排） |
| ＋ 向下插入 | 在下方插入空白步骤 | 序号自动顺延 |
| 🗑 删除 | 删除当前步骤 | 其余步骤序号自动重排 |

> 上述按钮在**样例数据行（frozen 只读行）**中不显示，避免对模板数据误操作。

### 21.5 子列筛选（漏斗）

步骤名称 / 预期结果 / 数据 三个子列表头各带漏斗图标，可独立筛选：

| 元素 | 功能 |
|------|------|
| 子列漏斗 | 按该子列内容过滤步骤（仅影响子表格内步骤显示，不影响主表行） |
| 蓝色高亮 | 有筛选条件的子列漏斗高亮 |

### 21.6 子列宽调整

| 操作 | 方式 |
|------|------|
| 拖动调整子列宽 | 拖动子表头右侧分割线（`.xs-sub-resizer`） |
| 持久化 | 子列宽随文件状态持久化（见第十九章），拖动后切换 Tab 自动恢复 |

默认子列宽：`[序号 32, 步骤名称 132, 预期结果 128, 数据 72, 操作 60]`，总和 404px。

### 21.7 查找高亮在子表格中的行为

展开状态下，查找（`Ctrl/Cmd + F`）命中步骤名称 / 数据 / 预期结果时，会**在对应子单元格内直接高亮匹配文本**：

- 步骤名称（`xse-td-desc`）：纯文本，按行 `markText` 高亮
- 数据 / 预期结果（`xse-line` / chip 结构）：使用结构化高亮（`markTextInStructure`），保留原有 DOM 结构不破坏

### 21.8 与弹窗编辑的关系

- **未展开**：双击步骤列（蓝色明细链接）打开「步骤明细弹窗」（见 15.1）编辑。
- **已展开**：原地内联编辑，无需弹窗；两者读写同一份 `rawRowGroups` 源数据，保持一致。
- 切换展开/收起时，编辑内容自动同步，不会丢失。
