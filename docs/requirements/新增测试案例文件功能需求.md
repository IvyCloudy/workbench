# 新增测试案例文件功能需求文档

> 文档视角：业务 / 用户（案例编辑者、测试负责人）
> 适用范围：在「测试任务 / <子任务文件夹> / 测试案例 /」目录体系下，通过资源管理器右键或命令面板快速新建测试案例文件（CSV / YAML）
> 说明：本文档描述用户需要的能力、业务规则与验收标准，不涉及具体实现方式。

---

## 1. 总体背景与目标

测试案例以 CSV / YAML 文件形式维护于「测试任务」目录体系下。过去新建案例文件需手动创建文件、对照模板补齐表头与占位字段，门槛高且易出错（表头顺序错、testcase_id 占位不规范等会直接导致后续推送失败）。本功能目标是提供"一键新建 + 模板预填 + 自动打开编辑"的轻量入口，让用户把精力放在写案例内容上。

总体目标：
1. **多入口新建**：资源管理器右键「测试案例」目录 / 文件，或命令面板执行命令，均可触发新建。
2. **格式可选**：支持 CSV（表格格式，推荐结构化案例）与 YAML（层次化格式，适合复杂步骤）两种格式。
3. **模板预填**：新建文件自带标准表头 / 字段结构与示例占位，降低录入门槛，并保证后续推送可被正确解析。
4. **命令创建可追溯**：命令创建的文件被记录标识，编辑器首行显示装饰器、状态栏提示、推送来源判定为 testAgentMA，且重命名 / 删除自动同步记录。

---

## 2. 术语与前提

| 术语 | 业务含义 |
|------|----------|
| 测试案例目录 | 固定目录名 `测试案例`，文件必须位于该目录或其子文件夹下才被识别为案例 |
| 命令创建 | 通过右键「新增测试案例」子菜单或命令面板命令创建的文件，与用户手动新建相区分 |
| 模板示例行 | 新建模板中 testcase_id 为占位「案例唯一标识，不可修改」的示例数据行，推送时会被过滤 |
| 命令创建记录 | 工作区 `.plugin/.tms/testcase-viewer/created-files.json` 中记录的命令创建文件路径与元数据 |
| 推送来源 | 推送时标识文件来自 testAgent 还是 testAgentMA，命令创建文件固定判为 testAgentMA |

## 3. 功能需求

### 3.1 新建入口触发

#### 需求背景与目标
新建入口需贴合用户操作习惯：在资源管理器中右键目标目录最自然，命令面板则适合键盘流。两类入口都需限定在「测试案例」目录体系内，避免游离文件。

#### 交互与功能规则
- **资源管理器右键子菜单**：在 `测试任务 / <任务名> / 测试案例` 文件夹（或其下任意子文件夹、或其下的 .csv/.yaml/.yml/.json 文件）上右键，上下文菜单出现「新增测试案例」子菜单，展开后含「CSV (.csv)」与「YAML (.yaml)」两项；右键文件时以文件所在目录为创建目录。
- **命令面板入口**：命令面板可检索「新增测试案例」，执行后弹出格式选择 QuickPick（CSV / YAML，CSV 在前），选择后按当前活动文件所在测试案例目录创建。
- **快速创建命令**：命令面板提供「新增测试案例(快速)」，在活动文件位于测试案例目录下时可直接以该目录为目标创建并弹格式选择；非测试案例目录时给出警告且不创建文件。
- **入口隔离**：「新增测试案例」菜单仅出现在测试案例目录 / 文件上，测试大纲等其它位置不显示，与「新增测试要点」菜单互不串菜单。

### 3.2 目录校验

#### 需求背景与目标
新建位置必须落在「测试案例」目录体系内，否则文件将不被识别为案例、后续无法推送。需在校验失败时给出明确提示而非静默生成游离文件。

#### 交互与功能规则
- **合格目录创建**：目标路径包含「测试案例」字样时校验通过，文件创建于该目录（右键文件夹即其自身，右键文件即其 dirname，子文件夹内创建保持层级不提升）。
- **非合格目录拒绝**：目标路径不含「测试案例」时，弹出警告「只能在测试案例目录或其子文件夹中创建新测试案例」并终止，不创建任何文件，不破坏工作区结构。

### 3.3 格式选择与模板内容

#### 需求背景与目标
CSV 与 YAML 两种格式面向不同场景，模板需各自预填正确结构，使新建文件可直接打开编辑并能被推送解析。

#### 交互与功能规则
- **子菜单免弹窗**：右键子菜单直接选「CSV / YAML」时跳过格式 QuickPick，按所选扩展名直接创建（CSV 用 `case_example.csv` 模板，YAML 用 `case_example.yaml` 模板）。
- **命令面板弹窗选择**：无预设格式时弹出 QuickPick 列出 CSV / YAML（描述分别为"表格格式，推荐用于结构化案例"与"层次化格式，适合复杂步骤"），取消选择则不创建文件。
- **CSV 模板结构**：表头含 testcase_id、路径、名称、案例描述、前置条件、步骤描述、预期结果、案例类型、优先级、执行方式（共 10 字段），首行 testcase_id 为占位「案例唯一标识，不可修改」，示例行含步骤描述 / 预期结果的换行占位。
- **YAML 模板结构**：含 testcase_id、path、name、description、preconditions、steps（steps 含 operation、data、ui_expected、api_expected、db_expected）、tags、type、test_type、priority；testcase_id 同样为「案例唯一标识，不可修改」占位。
- **占位文案一致**：模板示例行 testcase_id 占位文案与系统常量（中文「案例唯一标识，不可修改」、短占位「案例唯一标识」、英文占位 `TESTCASE_ID`）保持一致，用于推送时识别并过滤示例行。

### 3.4 默认文件名与同名处理

#### 需求背景与目标
新建文件需有合理默认名并进入改名态，用户输入即覆盖；同名时自动递增避免覆盖既有文件。

#### 交互与功能规则
- **默认命名**：首次创建默认名为「未命名测试案例.<ext>」，文件创建后自动进入资源管理器 inline 编辑（文件名输入框聚焦），用户直接输入新名回车即按新名保存。
- **同名递增**：目录已存在同名文件时自动递增为「未命名测试案例1.<ext>」「未命名测试案例2.<ext>」……序号连续无跳号、不覆盖既有文件。

### 3.5 打开与编辑

#### 需求背景与目标
新建后应立刻进入可编辑状态，使用案例专属编辑器呈现表格视图，而非纯文本，降低首次使用门槛。

#### 交互与功能规则
- **专属编辑器打开**：CSV / YAML 文件创建后以「测试案例编辑器（unifiedEditor）」自定义编辑器打开，表头与示例行渲染为表格；编辑器打开失败时降级为文本编辑并提示错误。
- **inline 重命名**：创建后执行 revealInExplorer + 延时 100ms + renameFile 触发 inline 改名；修改扩展名时模板内容随之转换（CSV↔YAML）。
- **重命名超时兜底**：注册 onDidRenameFiles 监听并以 setTimeout(30000) 兜底 dispose，用户 30 秒内未重命名则监听器自动释放，避免资源泄漏。

### 3.6 命令创建标识

#### 需求背景与目标
命令创建的文件需与用户手动新建区分，以支持推送来源判定、装饰提示与生命周期跟踪，同时记录写盘零侵入。

#### 交互与功能规则
- **写入创建记录**：创建成功后绝对路径作为 key 写入 `.plugin/.tms/testcase-viewer/created-files.json`，记录项含 `createdAt`（ISO8601）与 `version`（'1.0'）；key 为绝对路径，跨工作区不共享记录，不影响原文件内容。
- **首行装饰器**：命令创建文件在编辑器首行显示绿色 📝 装饰器；手动创建的同格式文件不显示。
- **状态栏信息**：打开命令创建文件时状态栏显示「通过命令创建」及创建时间 / 版本（1.0）；关闭文件后状态栏项消失。
- **重命名 / 删除同步**：文件重命名后记录 key 自动更新为新路径；删除后对应记录自动移除；`cleanupRecords` 清理已不存在文件的滞留记录，操作幂等。

### 3.7 推送来源与示例行过滤

#### 需求背景与目标
命令创建的案例文件推送时来源应判为 testAgentMA；模板示例行不能当作真实业务数据上报。

#### 交互与功能规则
- **推送来源判定**：命令创建文件（无论 testcase_id 取值）→ `testAgentMA`；非命令创建但存在以 `TC` 开头的 testcase_id → `testAgent`；其余兜底 → `testAgentMA`。
- **中文占位静默过滤**：testcase_id 为中文「案例唯一标识，不可修改」或短占位「案例唯一标识」的示例行，推送前静默过滤，不发送到后端。
- **全样例提示**：选中的全部为示例行时终止推送，提示「为样例数据」并列出具体行号（弹窗行号可点击跳转主表对应行）。
- **英文占位阻断**：testcase_id 为英文占位 `TESTCASE_ID`（大小写不敏感）时阻断推送并弹窗，由调用方单独处理，与中文占位的静默过滤策略区分。
- **字段必填校验**：推送映射时 testcase_id、步骤描述 / steps、预期结果 / 每个 step 的 ui_expected/api_expected/db_expected 至少其一为必填，缺失则拦截并提示含行号（YAML 含 stepIdx）；中文 CSV 与 YAML 各自的兜底规则（案例类型空→功能点类、优先级空→低、执行方式空或手工→手工、YAML type 固定功能点类、路径标准化统一斜杠并补全首尾斜杠）均按既定映射执行。

## 4. 用户操作流程

### 4.1 右键新建测试案例
1. 在资源管理器定位到「测试任务 / 任务A / 测试案例」文件夹（或其子文件夹）。
2. 右键该文件夹，选择「新增测试案例 → CSV (.csv)」（或 YAML）。
3. 文件以默认名创建并进入 inline 改名态，同时以表格编辑器打开，模板已预填表头与示例占位。
4. 重命名文件、替换示例行内容、补充真实案例后推送。

### 4.2 命令面板新建
1. 打开命令面板（Cmd/Ctrl+Shift+P），输入「新增测试案例」回车。
2. 在格式 QuickPick 中选择 CSV 或 YAML。
3. 文件按当前活动文件所在测试案例目录创建并打开。

### 4.3 推送命令创建的文件
1. 命令创建的案例填入真实 testcase_id 与案例内容。
2. 推送时来源判定为 testAgentMA；模板示例行被静默过滤，仅真实案例上报。
3. 若仅保留示例行，提示「为样例数据」并列出可跳转的行号。

## 5. 异常与边界

| 场景 | 期望行为 |
|------|----------|
| 右键测试大纲目录 | 不出现「新增测试案例」菜单，仅出现「新增测试要点」 |
| 命令快速创建在非测试案例目录 | 警告且不创建文件 |
| 目标路径不含「测试案例」 | 警告「只能在测试案例目录或其子文件夹中创建」并终止 |
| 格式 QuickPick 取消 | 不创建任何文件、无残留 |
| 目录已存在同名文件 | 自动递增命名，不覆盖 |
| 连续多次同名创建 | 依次递增 1、2、3…无跳号无冲突 |
| 模板文件读取失败（缺失/权限） | 错误提示且不创建空文件 |
| 用户 30 秒未重命名 | 重命名监听自动释放，无异常 |
| 命令创建后重命名文件 | 记录 key 更新为新路径，装饰/状态栏仍生效 |
| 命令创建后删除文件 | 记录对应 key 移除，无滞留 |
| 推送仅含示例行 | 提示「为样例数据」并列出可跳转行号 |
| 推送英文占位 TESTCASE_ID | 阻断并弹窗，列出行号 |
| 推送缺 testcase_id/步骤/预期 | 拦截并提示含具体行号 |

## 6. 验收标准

1. **多入口可用**：资源管理器右键（目录/文件/子文件夹）与命令面板均可在测试案例目录下触发新建；非测试案例目录不出现该菜单。
2. **格式可选 + 模板正确**：CSV / YAML 均可创建；模板表头 / 字段结构 / 示例占位（testcase_id「案例唯一标识，不可修改」）正确，可直接被编辑器打开与推送解析。
3. **命名与打开**：默认名「未命名测试案例.<ext>」、同名自动递增、创建后 inline 改名并以表格编辑器打开；修改扩展名时模板内容随之转换。
4. **命令创建可追溯**：写入 created-files.json（含 createdAt / version）、首行 📝 装饰、状态栏「通过命令创建」；重命名 / 删除自动同步记录。
5. **推送语义正确**：命令创建文件来源判为 testAgentMA；示例行按中文占位静默过滤、全样例提示、英文占位阻断；必填字段缺失拦截并含行号定位。
