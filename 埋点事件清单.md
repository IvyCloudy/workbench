# 埋点事件清单

> 对接 API：
> ```ts
> sendTelemetryEvent(eventName: string, props?: StringGenerateProperties)         // 普通事件
> sendTelemetryErrorEvent(eventName: string, props?: StringGenerateProperties)     // 错误事件
> sendTelemetryException(eventName: string, props?: StringGenerateProperties)      // 异常事件
> ```
> `StringGenerateProperties = { [key: string]: string }`，所有 prop 值均为 `string`。
>
> 源码位置：`src/services/telemetry.ts`  ·  `stackHead()` 和 `sendTelemetryException` 均已导出。

| **推送失败数** | `sum(parseInt(editorPush.complete.failedRows))` + `sum(parseInt(explorerPush.complete.failedRows))` |
| **推送成功数** | `sum(parseInt(editorPush.complete.successRows))` + `sum(parseInt(explorerPush.complete.successRows))` |

| **推送被拒绝次数** | `count(explorerPush.aborted)` |

| **删除行数** | `sum(parseInt(editor.saved.removeRows))` |

| **修改单元格数** | `sum(parseInt(editor.saved.changeCells))` |

## 四、props 字段说明

> 所有值为 `string` 类型，数值字段分析端按需 `parseInt / parseFloat`。

| 字段 | 说明 | 取值示例 | 出现事件 |
|------|------|----------|----------|
| `fileFormat` | 文件格式 | `csv` / `yaml` / `json` | `editor.*` 系列 |
| `targetFile` | 文件名/路径 | `testcases.csv` | `editor.opened.unqualified`, `editor.waitReady.timeout` |
| `ext` | 文件扩展名 | `.csv` / `.yaml` / `.json` | `editorPush.*`, `explorerPush.*` |
| `pushResult` | 推送结果 | `allSuccess` / `partial` / `allFail` | `editorPush.complete`, `explorerPush.complete` |
| `returnCode` | 后端返回码 | `SUC0000` / 错误码 / `UNBOUND` | `api.*.fail`, `editorPush.failed`, `explorerPush.failed`, `tableBrowser.send.failed` |
| `httpStatus` | HTTP 状态码 | `200` / `500` | `api.pushTestCase.*` |
| `command` | 命令 ID | `tableBrowser.open` / 等 6 种 | `command.executed` |
| `execResult` | 命令执行结果 | `folderNotExist` | `command.executed` |
| `reason` | 拒绝原因 | `multiFile` / `dirNotQualified` / `unbound` / `noData` / `notTestCaseFile` / `unsupportedFileType` / `selfSaveGuard` | `explorerPush.aborted`, `syncDeletedRows.aborted`, `editor.visibleChange.skipped` |
| `origin` | 变更来源 | `fsWatcher` / `onDidSaveTextDocument` | `editor.externalChange.*` |
