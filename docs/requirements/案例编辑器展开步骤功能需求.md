# 案例编辑器展开步骤功能需求文档

> 文档视角：业务 / 用户（测试人员、案例编辑者、测试负责人）
> 适用范围：表格编辑器中的 YAML / JSON 测试案例文件，针对 `steps`（步骤）列提供的"在主表内联展开 / 收起为子表格"的编辑与浏览能力
> 说明：本文档描述用户需要的能力、业务规则与验收标准，不涉及具体实现方式。
> 章节约定：每个功能模块均按「需求背景与目标」「交互与功能规则」两部分展开。

---

## 1. 总体背景与目标

在 YAML / JSON 测试案例中，一条案例往往包含多个步骤（操作、数据、各类预期结果）。折叠态下，编辑器为节省空间将整组步骤显示为「[N 项]」聚合文本，用户需逐个点击弹窗才能查看与编辑，步骤之间的顺序与全貌难以一览，批量维护步骤（增删、改预期、核对）效率偏低。

本功能目标是：在案例编辑器主表的 `steps` 列上，提供「展开步骤 / 收起步骤」开关，将折叠的聚合文本**直接展开为内联子表格**，让用户在不离开主表的前提下，像编辑普通表格一样查看、增删、改每一步的操作与预期；同时支持子表格的列筛选、列宽调整、状态持久化，并保证与折叠态、推送、样例冻结、撤销重做等场景无缝协同。

总体目标：
1. **主表内联展开**：YAML / JSON 案例中，`steps` 列可由折叠聚合文本一键展开为内联子表格（序号 / 步骤描述 / 预期结果 / 数据 / 操作），无需弹窗。
2. **内联步骤编辑**：展开态下可直接增、删、复制步骤，编辑步骤描述 / 数据 / 预期结果，并即时写回底层数据模型。
3. **预期分组结构化**：预期结果支持「UI 检查 / 接口调用 / 数据检查」三类分组，分别归位到对应字段，呈现分色、互不串写。
4. **子表浏览增强**：子表支持按步骤描述 / 预期结果等子列筛选，子列宽可拖动 / 双击自适应并持久化。
5. **状态协同与边界稳健**：展开态可持久化恢复；与折叠态编辑、推送、样例冻结行、撤销重做、文件切换等场景保持状态一致，不对 CSV 等非结构化格式提供该入口。

## 2. 术语与前提

| 术语 | 业务含义 |
|------|----------|
| 结构化案例文件 | 底层为 YAML / JSON 的案例文件，步骤以对象数组形式存在，可被结构化展开 |
| 折叠态 | `steps` 列显示为「[N 项]」聚合文本，点击进入步骤明细弹窗进行编辑 |
| 展开态 | `steps` 列在主表内联渲染为子表格，直接查看与编辑每一步 |
| 步骤子表格 | 展开态下 `steps` 列内部渲染的表格，含序号、步骤描述、预期结果、数据、操作列 |
| 预期分组 | 预期结果列内的「UI 检查 / 接口调用 / 数据检查」三类结构化分组，分别对应 ui_expected / api_expected / db_expected |
| 样例数据行 | 模板示例行（testcase_id 为占位），展开态下只读、不可编辑 |
| 子列筛选 | 针对步骤子表格中某一子列（如步骤描述、预期结果）的关键字过滤 |

## 3. 功能需求

### 3.1 展开入口的显隐规则

#### 需求背景与目标
展开步骤仅对"真正具备可展开结构"的文件有意义。应在合适的文件类型与字段下才暴露入口，避免对 CSV 或不含步骤的文件误给入口，造成困惑。

#### 交互与功能规则
- **结构化且含 steps 列时显示**：打开 YAML / JSON 案例文件，且表头（字段）中存在 `steps` 列时，工具栏显示「展开步骤」按钮；按钮提示语说明其作用为"将步骤展开为【步骤描述】+【预期结果】合并文本"。
- **CSV 文件隐藏**：CSV 文件的步骤列只是合并文本、无嵌套结构，无论是否含名为 steps 的文本列，均不显示「展开步骤」按钮，避免误导。
- **结构化但无 steps 列时隐藏**：YAML / JSON 文件若不含 `steps` 字段，不显示该按钮，不误提供展开入口。
- **表头内联入口**：除工具栏按钮外，`steps` 列主表头内提供内联的展开 / 收起箭头，点击效果与工具栏按钮完全一致；展开态下该处变为收起箭头。

### 3.2 展开与收起切换

#### 需求背景与目标
展开 / 收起是核心开关动作，应在主表 `steps` 列上完成"聚合文本 ↔ 内联子表格"的形态切换，并给出清晰的视觉与文案反馈。

#### 交互与功能规则
- **点击展开**：点击「展开步骤」后，原显示「[N 项]」的 `steps` 列切换为内联子表格；每行按步骤顺序排列，显示序号、步骤描述、预期结果、数据、操作（增 / 删 / 复制）按钮；有步骤的行正常展开。
- **按钮文案联动**：展开后按钮文案变为「收起步骤」；再次点击即执行收起。
- **点击收起**：收起后 `steps` 列恢复为「[N 项]」折叠聚合文本，按钮文案回「展开步骤」；若本次有行从展开态回归折叠，给出「已收起 X 行步骤」的提示。
- **空步骤行不展开**：某行 `steps` 为空数组时，展开态下保持为空标记（如 `[]`），不渲染子表格、不报错，有步骤的行不受影响。
- **展开态点击不弹明细弹窗**：展开态下点击步骤单元格不再弹出步骤明细弹窗，直接在内联子表格内编辑，与折叠态（点击弹窗）行为明确区分。

### 3.3 展开态内联步骤编辑

#### 需求背景与目标
展开的核心价值是"不离开主表即可维护步骤"。应支持对步骤的增、删、复制与逐字段编辑，并实时同步回底层数据模型与折叠态合并文本。

#### 交互与功能规则
- **添加步骤**：子表每行提供「+」添加按钮，点击在**当前步骤之后**插入一个空步骤（非末尾追加），其余步骤序号顺延重排，主表步骤计数 +1，新行可内联输入。
- **删除步骤并序号重排**：点击某步骤的删除按钮，该步骤从子表移除，剩余步骤序号重新连续编号，主表步骤计数 -1。
- **复制步骤（深拷贝）**：点击复制按钮，生成内容相同的副本步骤并插入其后；副本与原步骤数据相互独立，修改副本不影响原步骤任何字段。
- **编辑单元格写回**：在子表格中修改步骤描述 / 数据 / 预期结果并失焦后，内容写回对应步骤字段，主表 `steps` 合并文本同步更新，再次展开内容保持。
- **数据列内联编辑**：「数据」列支持多行输入，失焦后逐行写回步骤的数据数组；清空内容后该字段从数据模型中移除。
- **历史冗余前缀自动剥离**：若步骤描述被历史遗留累积了「步骤N …」之类的冗余前缀，展开时自动剥离为干净正文，保存后写回干净值，避免反复累积。
- **对象元素序列化为 JSON**：步骤的数据或预期值若含对象 / 数组元素，展开渲染为 JSON 文本（而非 `[object Object]`），且可正确回写、落盘与再次还原。

### 3.4 预期结果的三类分组

#### 需求背景与目标
预期结果常需区分 UI 校验、接口断言、数据校验三类。展开态下应提供结构化分组入口，使每类预期归位到对应字段，呈现分色、互不串写。

#### 交互与功能规则
- **添加 UI 检查分组**：在预期结果列点击「添加分组」选择「UI 检查」并输入内容，内容写入该步骤的 UI 预期字段（ui_expected）；不输入直接失焦则不进入数据模型。
- **添加接口调用分组**：选择「接口调用」并输入接口断言内容，写入接口预期字段（api_expected）；该分组标题以紫色系区分。
- **添加数据检查分组**：选择「数据检查」并输入 SQL / 数据校验内容，写入数据预期字段（db_expected）；该分组标题以绿色系区分。
- **多分组共存与分色**：同一预期结果列可同时存在 UI 检查（蓝）/ 接口调用（紫）/ 数据检查（绿）三类分组，按固定顺序渲染，且三类内容分别写入各自字段、互不串写；保存后 YAML 三类分组标题与内容均正确落盘，再次展开完整还原。
- **纯文本兜底为 UI 预期**：预期结果列直接输入多行文本（不点任何分组按钮）时，内容归入 UI 预期字段；不应把"添加分组"等按钮文字误写入数据。
- **同类不可重复添加**：某预期结果列已添加某类型分组后，该类型的添加按钮消失（每类仅一个分组），其余类型按钮仍可用，已填内容保留不丢失。

### 3.5 子表格浏览增强（筛选与列宽）

#### 需求背景与目标
步骤较多时，用户需要在子表内快速聚焦特定步骤、或调整可读性。应提供子列筛选与子列宽调整能力，并保持列宽设置持久化。

#### 交互与功能规则
- **子列筛选漏斗**：子表支持对「步骤描述」「预期结果」等子列开启筛选漏斗，输入关键字后仅显示命中的步骤；某单元格所有步骤均被过滤时，显示"当前子列筛选下，该单元格所有步骤均被隐藏"的空占位；清除筛选后所有步骤恢复。
- **子列宽拖动与双击自适应**：拖动子列（序号 / 步骤描述 / 预期结果 / 数据 / 操作）右侧分隔条可改变列宽，内部子表与主表头严格对齐；双击子列表头按可见内容自适应列宽；折叠 → 展开后子列宽仍保持上次设置（持久化生效）。

### 3.6 状态协同与边界

#### 需求背景与目标
展开步骤不是孤立功能，需与编辑器其它能力（推送、样例冻结、撤销重做、文件切换、状态持久化）协同，保证任意切换下状态一致、无错位、不报错。

#### 交互与功能规则
- **样例数据行只读**：展开态下，模板示例（样例数据）行子表为只读，不显示添加 / 删除 / 复制 / 添加分组等操作按钮；点击操作按钮提示"样例数据行已冻结，不可操作"。
- **撤销 / 重做自愈对齐**：执行撤销或重做导致数据被快照覆盖后，展开态仍保持为内联合并文本、折叠态仍保持为「[N 项]」，按钮状态与内容一致，无错位。
- **展开态持久化恢复**：展开状态被记录，关闭并重开编辑器（或切走再切回、推送反弹后）默认仍处于展开态（无闪烁），按钮文案同步为「收起步骤」，子表内容正确还原。
- **缺失 steps 列静默降级**：在展开态下切换到不含 `steps` 列的文件时，自动降级为折叠态、不报错，按钮文案回「展开步骤」；切回含 steps 文件后行为正常。

## 4. 用户操作流程

### 4.1 展开并浏览步骤
1. 打开一个 YAML / JSON 测试案例文件，确认表头含 `steps` 列、工具栏出现「展开步骤」按钮。
2. 点击「展开步骤」（或 `steps` 列表头内联箭头），`steps` 列由「[N 项]」切换为内联子表格。
3. 在子表中按序号浏览每一步的操作、数据、预期结果；点击工具栏按钮文案变为「收起步骤」。

### 4.2 展开态内联维护步骤
1. 展开后，点击某步骤行的「+」在其后插入空步骤，或点击删除 / 复制维护步骤；序号自动重排。
2. 在子表格直接修改步骤描述、数据、预期结果并失焦，内容即时写回主表与底层数据。
3. 在预期结果列按「UI 检查 / 接口调用 / 数据检查」添加分组并输入，三类预期分色归位、互不串写。

### 4.3 子表筛选与列宽
1. 对「步骤描述」或「预期结果」子列开启筛选漏斗，输入关键字聚焦目标步骤；清空恢复全部。
2. 拖动子列分隔条调整列宽，或双击表头自适应；折叠再展开后宽度保持。

### 4.4 收起与状态恢复
1. 点击「收起步骤」，`steps` 列恢复「[N 项]」，按钮文案回「展开步骤」，给出已收起行数提示。
2. 展开后关闭并重开编辑器，默认仍处于展开态、子表内容正确还原；切换到无 steps 文件自动降级为折叠态。
3. 对样例数据行展开时子表只读，点击操作按钮提示已冻结。

## 5. 异常与边界

| 场景 | 期望行为 |
|------|----------|
| 打开 CSV 案例文件 | 不显示「展开步骤」按钮（无论是否含 steps 文本列） |
| YAML/JSON 文件无 steps 字段 | 不显示「展开步骤」按钮 |
| 某行 steps 为空数组 | 展开态下保持空标记，不渲染子表、不报错 |
| 展开态点击步骤单元格 | 不弹明细弹窗，直接内联编辑 |
| 添加步骤 | 插入到当前步骤之后，序号顺延，主表计数 +1 |
| 复制步骤 | 深拷贝副本，与原步骤相互独立 |
| 预期结果直接输入纯文本 | 归入 UI 预期，不误写"添加分组"按钮文字 |
| 同预期列重复添加同类型分组 | 该类型按钮消失，不可重复添加 |
| 三类分组共存 | 按 UI(蓝)/接口(紫)/数据(绿) 分色，分别写回各自字段 |
| 步骤数据 / 预期含对象元素 | 渲染为 JSON 文本，可回写与落盘 |
| 子列筛选无命中 | 单元格显示空占位提示，清除后恢复 |
| 样例数据行展开 | 子表只读，无操作按钮，点击提示已冻结 |
| 撤销 / 重做 | 展开态仍内联、折叠态仍聚合，按钮与内容一致无错位 |
| 展开态关闭重开 / 切回 | 默认保持展开态，无闪烁，内容正确还原 |
| 展开态切到无 steps 文件 | 静默降级折叠态，不报错，切回正常 |
| 历史冗余「步骤N」前缀 | 展开自动剥离为干净正文，保存写回干净值 |

## 6. 验收标准

1. **入口显隐正确**：YAML/JSON 且含 `steps` 列时显示「展开步骤」按钮与表头内联箭头；CSV 文件、无 `steps` 字段的结构化文件均不显示入口。
2. **展开 / 收起切换**：点击在「[N 项]」聚合文本与内联子表格间切换；按钮文案在「展开步骤 / 收起步骤」间联动；收起给出已收起行数提示；空步骤行不渲染子表；展开态点击不弹明细弹窗。
3. **内联步骤编辑**：支持在展开态增 / 删 / 复制步骤（插入到当前步骤之后、序号重排、计数同步）；修改步骤描述 / 数据 / 预期结果即时写回底层与合并文本；对象元素以 JSON 呈现可回写；历史冗余前缀自动剥离。
4. **预期三类分组**：预期结果列支持 UI 检查 / 接口调用 / 数据检查三类分组，分色分别归位 ui_expected / api_expected / db_expected，互不串写；纯文本兜底为 UI 预期；同类不可重复添加；保存与再次展开完整还原。
5. **子表浏览增强**：子列筛选漏斗作用于步骤描述 / 预期结果等子列，无命中显示空占位、可清除恢复；子列宽可拖动 / 双击自适应并持久化，与主表头对齐。
6. **状态协同稳健**：样例数据行展开只读；撤销 / 重做后展开 / 折叠形态自愈对齐；展开态可持久化恢复（无闪烁）；切到无 steps 文件静默降级折叠态。
