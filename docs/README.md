## 📝 文档维护约定

1. **新增文档** → 优先放入 `guides` / `specs` / `architecture` 之一；不要堆放在仓库根目录。
2. **一次性总结** → 归入 `history/`，并在文档开头标注产出日期。
3. **链接相对路径** → 使用 `[文本](相对路径.md)`，避免硬编码 GitHub URL。
4. **重大变更** → 同步更新本索引（`docs/README.md`）与根 [`README.md`](../README.md) 的「文档导航」表。
