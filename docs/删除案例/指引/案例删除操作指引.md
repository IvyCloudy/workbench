## 一、功能概述

「案例删除」是把本地测试案例文件**从平台与本地同步清理**的功能。根据文件当前是否已推送到测试任务管理系统（TMS）、以及案例在平台上的状态，删除动作会自动走不同的链路：

- **已推送且平台存在**的案例 → 调用平台接口真实删除，并清理本地；
- **已推送但存在执行/缺陷关联**的案例 → 先弹出确认窗口告知关联，确认后再删除；
- **从未成功推送（平台已不存在）**的案例 → 仅清理本地，无需二次确认；
- **含 CMBT 关联**等平台禁止删除的情况 → 保留原文件、不删除，提示原因。

**核心能力：**
- 三个入口：**编辑器内删行**、**删除单个文件**、**批量删除多文件**
- 删除前自动预检任务绑定与案例在平台的状态，未绑定/异常时拒绝删除并提示
- 类型=3（平台已不存在）的文件在整批删除时**不弹确认窗**，直接清理本地
- 混合批量删除时，每一类文件（需同步 / 仅本地 / type=3 / 预检失败）在弹窗中逐一说明去向
- 删除结果按「平台已删除 / 平台无此案例 / 本地删除 / 失败」分档展示

## 二、三种删除入口

| 入口 | 操作位置 | 适用场景 |
|------|---------|---------|
| 编辑器内删行 | 表格编辑器内右键行 →「删除该行 / 删除选中行」 | 精准删除文件中的若干行 |
| 删除单个文件 | 资源管理器右键案例文件 →「删除案例文件」 | 整文件删除 |
| 批量删除 | 资源管理器多选文件 / 文件夹 → 右键「删除案例文件」 | 一次性删除多个案例文件 |

> ⚠️ 只有合规目录（`测试任务/<任务文件夹>/测试案例/`）下的文件才显示删除菜单，与推送目录约束一致。

## 三、删除前预检：案例在平台的四种状态

无论哪种入口，删除前插件都会对每一个待删案例调用预检接口，得到该案例在平台上的状态：

| 状态 | 含义 | 删除行为 |
|------|------|---------|
| `type=1` | 平台存在，允许直接删除 | 调用平台接口删除，本地同步清理 |
| `type=2` | 平台存在，但**有执行记录 / 缺陷关联** | 弹出确认窗口列出关联，**确认后**才删除 |
| `type=3` | 从未推送 / 平台已不存在 | 仅清理本地（平台侧已无此数据，无操作） |
| `type=4` | 含 CMBT 关联，平台禁止删除 | **不删除**，原文件保留，提示原因 |

> 💡 「本次同步删除到平台的案例数」只统计 `type=1 + type=2`（即真正会调用平台删除接口的行数），`type=3` 不计入该数字。

## 四、文件级分类与是否需要确认

插件会按「文件内待删案例的状态组合」把每个文件归入一类，并据此决定弹窗行为：

| 分类 | 触发条件 | 是否需要确认弹窗 | 说明 |
|------|---------|----------------|------|
| 需同步 TMS | 含 `type=1` / `type=2` 案例 | ✅ 需要 | 会真实调用平台删除接口；`type=2` 在弹窗中列出关联 |
| 仅本地删除（hardDeleteOnly） | 文件无 `testcase_id` 列 / 空文件 / 全部为本地未推送 | ❌ 不需要 | 不涉及平台，直接清理本地 |
| 全部 type=3 | 文件内所有待删案例均为 `type=3` | ❌ 不需要 | 平台已不存在，仅清理本地 |
| 未绑定测试任务 | 文件所在任务尚未与平台绑定 | ❌ 不需要 | 无平台接口可调，仅清理本地 |
| 预检失败 | 预检接口异常 / 无案例标识列 | ❌（但文件不会被删除） | 在弹窗中标红说明，本次跳过保留 |

**确认弹窗的触发规则（重点）：**
- 确认弹窗**仅由**「需同步 TMS 的非 type=3 文件」或「预检失败文件」触发；
- 若整批仅由 **type=3 文件** 与/或 **仅本地删除文件** 构成（没有任何需同步 / 预检失败文件）→ **整批不弹确认窗**，直接删除；
- 一旦本批中**任一文件**含需同步案例或预检失败 → 弹窗中会把 type=3 / 仅本地 / 预检失败文件也一并列出，逐个说明其去向。

## 五、方式一：编辑器内删除行

适用场景：需要**选择性删除**文件中的部分案例行。

#### 操作步骤

1. 在表格编辑器中**选中要删除的行**（点击行号格 / `Shift+点击` / `Ctrl(Cmd)+点击`）。
2. 右键被选中的行，选择 **「删除该行」** 或 **「删除选中行」**。
3. 插件执行预检：
   - **未绑定任务**：弹简单确认「删除仅清理本地，不会同步到平台」→ 确认后直接删。
   - **预检失败 / 接口异常**：弹窗告知「删除前校验未通过」，本次删除已取消（不会删任何行）。
   - **含 `type=2` 关联案例**：弹出确认窗口，列出每条案例的执行/缺陷关联，确认后删除。
   - **文件内行全部为 `type=3`**：**不弹确认界面**，直接执行删除，删除结果界面照常展示。
4. 删除完成后，结果在编辑器内结果面板 / 弹窗中展示（见第八节）。

#### 界面示意

```
编辑器右键菜单
┌─────────────────────────────────────┐
│  插入一行                            │
│  删除该行            ← 单选一行      │
│  删除选中行          ← 多选时        │
│  仅看失败行                          │
└─────────────────────────────────────┘

含 type=2 关联时的确认窗口
┌─────────────────────────────────────┐
│  以下 N 条案例存在执行/缺陷关联：     │
│  #  编号      名称       执行 缺陷   │
│  1  TC_001   登录测试    Y    N      │
│  2  TC_002   搜索测试    Y    Y      │
│                    [取消]  [确认删除] │
└─────────────────────────────────────┘
```

## 六、方式二：删除单个案例文件

适用场景：**整文件删除**，由资源管理器右键触发。

#### 操作步骤

1. 在资源管理器中定位案例文件，右键 → **「删除案例文件」**。
2. 插件预检文件内所有待删案例并分类（见第四节）。
3. 按分类决定：
   - **全部 type=3 / 仅本地删除 / 未绑定任务** → 不弹确认窗，直接删除本地文件。
   - **含 `type=2` 关联案例** → 弹出文件级确认窗口，列出关联案例，确认后同步平台并删除本地。
   - **预检失败** → 弹窗提示，文件保留不被删除。
4. 删除后弹出结果窗口，分档展示成功 / 失败（见第八节）。

> 💡 整文件删除的结果窗口与编辑器内删行的结果面板为同款样式，便于对照。

## 七、方式三：批量删除案例文件

适用场景：一次性删除**多个文件**（多选文件或整个文件夹）。走独立的批量确认弹窗 + 结果总结视图。

#### 7.1 操作步骤

1. 在资源管理器中 `Ctrl(Cmd)+点击` / `Shift+点击` 选中多个案例文件，或右键选中文件夹。
2. 右键 → **「删除案例文件」**（批量模式）。
3. 插件对每个文件逐一预检并分类。
4. **判断是否需要确认弹窗**（见第四节规则）：
   - 整批仅 type=3 +/或仅本地删除 → **不弹窗**，直接删除。
   - 含需同步 / 预检失败文件 → 弹出批量确认弹窗（见 7.2）。
5. 确认后逐个文件执行删除，结束后展示批量结果总结。

#### 7.2 批量确认弹窗说明

弹窗顶部标题分段展示本批构成，例如：

```
共 4 个文件（2 需同步 TMS·6 案例 / 1 仅本地 / 1 仅本地清理(type=3)）
```

各文件以 **Tab** 形式列出，图标与徽标区分类型：

| 图标 | 徽标 | 含义 |
|------|------|------|
| ⚠ | 关联数 | 需同步 TMS，且含执行/缺陷关联案例 |
| 📄 | — | 需同步 TMS，无关联 |
| 🧹 | `type3` | 全部 type=3（平台已不存在，仅清理本地） |
| — | 行数 | 仅本地删除（hardDeleteOnly） |
| ⊘ | — | 预检失败，本次不会被删除 |

点击每个 Tab 查看该文件的说明：
- **需同步 TMS**：`删除本文件将同步删除 TMS 平台上的 N 条案例，以及这些案例的执行记录和缺陷关联。`
- **仅本地删除**：`仅删除本地文件（共 N 行），不涉及 TMS 平台。`
- **全部 type=3**：`该文件所有案例均未推送 TMS（type=3，平台已不存在）；删除将直接清理本地。`
- **未绑定任务**：`当前文件未绑定测试任务，删除仅清理本地，不会同步删除 TMS 平台上的案例。`
- **预检失败**：`预检失败，该文件不会被删除`（并附原因）。

顶部「谨慎操作」风险卡会汇总：存在关联案例的文件数/条数、仅本地删除文件数、type=3 文件数、预检失败文件数，让你在确认前看清全貌。

#### 7.3 与单文件删除的区别

| 维度 | 单文件删除 | 批量删除 |
|------|-----------|---------|
| 入口 | 右键单个文件 | 右键多选文件 / 文件夹 |
| 确认形态 | 简单确认弹窗 / 关联列表 | 聚合确认弹窗（Tab 逐文件说明） |
| 弹窗触发 | type=2 关联时弹 | 含需同步 / 预检失败文件时弹；纯 type=3+本地删除不弹 |
| 结果展示 | 单文件结果弹窗 | 批量总结视图（逐文件点击看明细） |
| 适用规模 | 一个文件 | 多文件、整文件夹 |

## 八、删除结果解读

删除完成后，结果按以下分档展示：

| 分档 | 对应状态 | 含义 |
|------|---------|------|
| 平台已删除 | `type=1` | 平台真实删除成功，本地同步清理 |
| 平台无此案例 | `type=3` | 平台侧本就不存在，仅本地清理 |
| 本地删除 | hardDeleteOnly / 未绑定任务 | 无平台数据，直接清理本地文件 |
| 失败 | `type=2`/`type=4`/接口异常 | 未删除，原文件保留，可重试 |

- 单文件结果弹窗给出成功数、失败数、失败明细（含原因与行号）。
- 批量总结视图顶部状态条显示 `<成功> 成功 / <失败> 失败 · 共 <文件数> 个文件`，点击文件名可查看该文件明细。
- **失败的行保留在文件中**（不会误删），可用编辑器「仅看失败行」筛选后修正重试。

> 💡 部分成功时，成功的行已被清理、失败的行留在文件里；文件不会被整文件删除，只有全部成功时才会真正移除本地文件。

## 九、常见问题

### Q1：为什么有的文件删除一点确认都不弹？

符合以下任一情况时不弹确认窗，直接删除：
- 文件内所有待删案例均为 `type=3`（从未推送、平台已不存在）；
- 文件无 `testcase_id` / 空文件 / 全部本地未推送（仅本地删除）；
- 文件所在任务未与平台绑定（仅清理本地）。

即：只有涉及「平台真实删除」或「预检失败」的文件才需要你在弹窗中确认。

### Q2：批量删除时，type=3 文件去哪了？

- 若整批都是 type=3 / 仅本地删除 → 不弹窗，全部直接删。
- 若本批混有需同步 / 预检失败文件 → type=3 文件会作为独立一类出现在弹窗 Tab 中（🧹 图标 + `type3` 徽标），说明「仅清理本地」，确认后同样被正常删除。

### Q3：删除提示「删除前校验未通过 / 校验异常」？

说明预检接口未通过（返回非成功码、网络异常、或任务信息获取失败）。此时**本次删除已取消、不会删任何数据**。可检查网络 / 任务绑定后重试。

### Q4：含执行/缺陷关联（type=2）的案例被删了会有什么后果？

这些案例在平台上关联着执行记录与缺陷。删除前会**强制弹窗列出关联**让你确认；确认后平台会一并解除关联并删除。请确认无误后再点「确认删除」。

### Q5：提示「含 CMBT 关联，不允许删除」？

平台禁止删除含 CMBT 关联的案例。该文件**不会被删除**，保留原状。需先在平台侧处理 CMBT 关联后再删除。

### Q6：type=3 的「平台无此案例」和「失败」有什么区别？

- 「平台无此案例」是**正常结果**：案例从未成功推送，平台侧本就没有，本地清理即完成。
- 「失败」是**未删除**：因关联 / 平台禁止 / 接口异常导致没删掉，文件保留可重试。

## 十、操作建议

### 删除前
- 批量删除前先确认本批文件构成，留意弹窗顶部「共 N 个文件（…）」分段与风险卡。
- 含 `type=2` 关联的文件务必看清关联清单再确认。

### 删除中
- 编辑器内删行时，预检 / 删除进行中行会处于「删除中」态，请勿重复触发。

### 删除后
- 查看结果分档：关注「失败」项，用「仅看失败行」定位并修正后重试。
- 批量删除后可在总结视图点击文件名，回顾每个文件的成功 / 失败明细。
